Carpeta publica para imagenes estaticas del frontend.

Todo archivo que pongas aqui quedara servido por Vite como recurso publico.

Ejemplos:

- `public/uploads/logo.png` -> `/uploads/logo.png`
- `public/uploads/mockups/home.jpg` -> `/uploads/mockups/home.jpg`

Usala para imagenes fijas del repo, no para archivos subidos por usuarios.
